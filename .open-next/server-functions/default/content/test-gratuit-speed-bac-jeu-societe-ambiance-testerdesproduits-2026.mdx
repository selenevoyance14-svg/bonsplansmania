Le **Speed Bac** est un jeu d'ambiance qui revisite le principe du petit bac qu'on connaît tous. Le concept :

- Les joueurs doivent répondre le plus vite possible à des **thèmes décalés**
- Il faut utiliser des **lettres imposées** par les cartes
