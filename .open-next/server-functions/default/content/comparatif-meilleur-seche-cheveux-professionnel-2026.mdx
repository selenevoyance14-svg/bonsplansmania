## Sèche-cheveux grand public vs professionnel : quelle différence ?

Les sèche-cheveux professionnels se distinguent par :
- **Moteur AC** (courant alternatif) vs DC : durabilité 5x supérieure
- **Puissance effective** plus importante
- **Ergonomie** pensée pour un usage prolongé (légèreté, équilibre)
- **Durée de vie** : 1000-2000h vs 300-500h pour le grand public
