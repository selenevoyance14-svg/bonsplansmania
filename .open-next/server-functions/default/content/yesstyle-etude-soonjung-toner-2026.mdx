# Etude SoonJung pH 5.5 Relief Toner

Le **Etude SoonJung pH 5.5 Relief Toner** est le toner K-beauty de référence pour les peaux sensibles. Formule minimaliste, pH idéal, zéro irritation.

## Pourquoi ce toner

- **pH 5.5** — respecte le pH naturel de la peau
- **97% d'ingrédients naturels** — formule clean
- **Panthénol + madecassoside** — duo apaisant puissant
- **Sans parfum, sans colorant** — zéro irritant
- **Grand format 350ml** — dure des mois

## La gamme SoonJung

SoonJung ("pur" en coréen) est la gamme **hypoallergénique** d'Etude :
- Testée dermatologiquement
- Adaptée aux peaux les plus réactives
- Minimaliste — le moins d'ingrédients possible

## Comment l'utiliser

1. Après le nettoyage, verser dans les mains
2. Presser doucement sur le visage
3. Ou appliquer au coton pour un léger exfoliant
4. Suivre avec sérum et crème
