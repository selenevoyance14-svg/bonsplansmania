## Comment utiliser un code cadeau ?

1. Choisissez le produit participant sur la boutique officielle.
2. Saisissez le code correspondant dans le panier.
3. Contrôlez la présence du cadeau et le total avant le paiement.

Un cadeau absent du récapitulatif ne doit pas être considéré comme acquis. Comparez également l’offre avec les packs et les tarifs des autres vendeurs, en tenant compte des accessoires réellement utiles.
