## Choisir son fond de teint selon son type de peau

### Peau mature : fonds de teint liftants et lumineux

Les **peaux matures** ont besoin de **textures fluides et légères**, **jamais épaisses** (qui s'**incrustent dans les rides**). Privilégier :

| Atout à rechercher | Pourquoi |
|---|---|
| **Acide hyaluronique** | **Repulpe** la peau de l'intérieur |
| **Vitamine C** | **Ravive l'éclat**, anti-taches |
| **Niacinamide** | **Anti-rougeurs**, lisse le grain |
| **Fini naturel lumineux** | **Effet bonne mine**, pas de plâtre |
| **Couvrance modulable** | **Couches fines successives**, jamais épaisses |

→ **Application** : à l'**éponge humide**, en tapotant du **centre vers l'extérieur** = effet liftant immédiat.

### Peau acnéique / imperfections : non comédogène impératif

Les **peaux à tendance acnéique** réagissent **très mal** aux formules grasses. Cherche :

| Atout | Détail |
|---|---|
| **Non comédogène** | **N'obstrue pas** les pores |
| **Sans huiles minérales** | **Pas de résidu** gras |
| **Texture fluide ou poudre** | **Légère**, non occlusive |
| **Matifiante** | **Contrôle le sébum** sans assécher |
| **Acide salicylique** (bonus) | **Action purifiante** intégrée |

### Peau sèche / sensible : hydratation prioritaire

| Atout | Détail |
|---|---|

| **Texture crème ou fluide riche** | **Confort**, pas de **craquellements** |

| **Fini satiné** | **Lumière** sans brillance |

### Peau mixte / grasse : matifiante longue tenue

| Atout | Détail |
|---|---|

## Comment trouver la bonne teinte

| Astuce | Détail |
|---|---|
| **Test sur la mâchoire**, pas le poignet | La teinte doit **fondre** avec le cou |
| **Lumière naturelle** (devant la fenêtre) | **Pas en magasin** sous néons |
| **Teste 2-3 teintes proches** | Voir laquelle disparaît le mieux |
| **Compte les sous-tons** | **Chaud** (jaune/doré), **froid** (rosé/beige), **neutre** |
| **Saison** | Plus **claire en hiver**, plus **dorée en été** |
| **Sample / mini-format** | **Avant l'achat plein** quand possible |

→ **Erreur classique** : choisir une teinte **trop foncée** ou **trop orangée** = effet **masque visible** dès qu'on bouge la tête.

## 5 gestes pro pour un fini naturel et sans transfert

### 1. Préparer la peau

| Action | Détail |
|---|---|
| **Hydrater** avec un soin adapté | Crème jour ou sérum |
| **Base de teint** lissante (primer) | **Floute les pores**, **prolonge la tenue** |
| **Laisser pénétrer** 1-2 minutes | Avant d'appliquer le fond de teint |

### 2. Choisir le bon outil

| Outil | Effet |
|---|---|
| **Pinceau plat à poils souples** | **Couvrance optimale**, finition lisse |
| **Pinceau Kabuki** | **Effet poudré**, fini velouté |
| **Beauty Blender humide** | **Effet seconde peau**, naturel |
| **Doigts** | **Chaleur** = bon pour les formules **crémeuses** |

→ **Astuce** : pour la **haute couvrance**, l'**éponge humide** est **imbattable** (étire la matière sans la diluer).

### 3. Appliquer du centre vers l'extérieur

- **Centre du visage** d'abord (front, nez, joues)
- **Mouvement circulaire** ou tapotements
- **Étirer la matière** vers les **contours**
- **Couches fines successives** plutôt qu'épaisses
- **Insister** sur les zones imparfaites avec **un peu plus** de matière

### 4. Fixer avec une poudre matifiante

- **Poudre libre translucide fine**, pas de poudre teintée (qui change la teinte)
- **Tapotements légers** avec une houppette ou un pinceau
- **Insister sur la zone T** (front, nez, menton)
- **Éviter** les contours du visage = peau sèche pour fondu naturel

### 5. Retoucher intelligemment

| Astuce retouche | Détail |
|---|---|
| **Poudre compacte** dans le sac | **Tampon** sur la zone T |
| **Beauty Blender propre** dans une trousse | Pour **fondre** une retouche |
| **Spray fixateur** mini-format | **Réhydrate** + relisse |
| **Pas de couches sur couches** | **Démaquille + refait** si trop chargé |

→ **Tapote**, ne **frotte jamais** = la matière reste en place.

## FAQ

**Quel est le fond de teint le plus couvrant au monde ?**

**Dermacol Make-Up Cover** est généralement reconnu comme le **fond de teint le plus couvrant** du marché grand public — il **camoufle tatouages**, **cicatrices marquées**, **vitiligos**. **Vichy Dermablend Fluide** offre une couvrance comparable avec une **texture plus légère**.

**Quel est le meilleur fond de teint couvrant pour les rides ?**

**Texture fluide** + **acide hyaluronique** + **niacinamide** sont les **3 critères clés**. Recommandations : **L'Oréal Age Perfect Sérum Foundation**, **Lancôme Teint Idole Ultra Wear**, ou **Vichy Dermablend Fluide**. **Évite** les compacts épais qui s'**incrustent** dans les ridules.

**Quel fond de teint pour cacher les imperfections (acné) ?**

**Non comédogène impératif**. **Maybelline Fit Me Matte + Poreless** ou **Dermacol Make-Up Cover** sont d'excellentes options. Pour un combo avec **soin** : **La Roche-Posay Effaclar BB**.

**Quel fond de teint couvrant et hydratant ?**

**La Provençale Bio**, **Erborian BB Cream**, **Tirtir Mask Fit Red Cushion** offrent une **bonne couvrance** + **hydratation** combinées. Idéal pour les **peaux sèches ou sensibles**.

**Quel fond de teint pour un résultat naturel ?**

**Couvrance moyenne modulable** + **texture fluide** = clés du **fini naturel**. **Bourjois Healthy Mix**, **Erborian Super BB**, ou **Tirtir Cushion** sont parfaits.

**Comment éviter l'effet plâtre ?**

| Astuce | Détail |
|---|---|
| **Couches fines** successives | Jamais une seule épaisse |
| **Préparation peau** soignée | Hydratation + primer |
| **Bonne teinte** (test mâchoire) | Évite le décalage cou/visage |
| **Pas de poudre teintée** | Translucide uniquement |
