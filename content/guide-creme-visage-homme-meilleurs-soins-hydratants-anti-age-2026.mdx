## Comment bien choisir sa crème visage homme

### Identifier son type de peau

| Type de peau | Texture recommandée | Actifs clés |
|---|---|---|
| **Normale** | Texture légère équilibrée | Glycérine, vitamine E |
| **Grasse** | Crème-gel matifiante | Zinc, niacinamide, acide salicylique |
| **Sèche** | Crème riche | Beurre de karité, acides gras essentiels |
| **Mixte** | Crème-gel bi-zones | Acide hyaluronique, zinc |
| **Sensible** | Texture minimaliste sans parfum | Aloe vera, panthénol |

### Identifier ses priorités

- **Hydratation simple** : crème jour légère + eau / aloe vera
- **Anti-fatigue** : vitamine C + magnésium + caféine
- **Anti-âge** : acide hyaluronique + peptides + rétinol + vitamine C
- **Après-rasage** : panthénol + aloe vera + sans alcool
- **Anti-imperfections** : zinc + niacinamide
- **Anti-taches** : niacinamide + extrait de réglisse + SPF

## La routine skincare homme parfaite

### Le matin (3 étapes max)

1. **Nettoyer** avec un gel moussant doux (sur peau humide, 30 secondes)
2. **Hydrater** avec ta crème jour (Vichy, Biotherm, Léa Nature, Avène, CeraVe…)
3. **Protéger** : sur peau dégagée → SPF 30 minimum si tu sors

### Le soir (3 étapes max)

1. **Démaquiller / nettoyer** (gel doux)
2. **Sérum anti-âge** ciblé (acide hyaluronique, vitamine C, peptides) — optionnel
3. **Crème de nuit** (Lierac, Clinique, Nuxe, Korres pour les 35+)

### 1 fois par semaine

- **Gommage doux** ou **masque détoxifiant** : affine le grain de peau, dégage les pores

### Pour les barbus

- **Huile à barbe** ou **soin barbe hydratant** en complément de la crème visage
- **Peigne barbe** + brossage quotidien pour répartir les actifs

## Comment bien appliquer ta crème visage

| Étape | Geste |
|---|---|
| 1 | **Quantité** : une noisette pour le visage entier |
| 2 | **Tiédir** entre les paumes 2 secondes |
| 3 | **Appliquer** du centre vers l'extérieur en mouvements circulaires |
| 4 | **Insister** sur front + contour des yeux + cou (ridules + relâchement) |
| 5 | **Massage** 30 secondes pour activer la microcirculation |
| 6 | **Attendre** 1-2 minutes avant maquillage / SPF |

**Fréquence** :
- **Peaux grasses** : 1 application/jour suffit
- **Peaux normales / mixtes** : matin + soir
- **Peaux sèches** : matin + soir, avec sérum riche le soir

---

## Les erreurs à éviter

- **Sauter l'étape SPF** : le soleil = facteur n°1 du vieillissement cutané
- **Mettre trop de produit** : 1 noisette suffit, sinon ça booche les pores
- **Changer de crème toutes les semaines** : la peau a besoin de **3-4 semaines** pour réagir
- **Ignorer le cou** : les rides du cou sont les plus marquantes après 40 ans
- **Crème qui pique** = pas adaptée → arrête immédiatement
- **Acheter 5 produits différents** au lieu d'**1 bonne crème + 1 sérum**
