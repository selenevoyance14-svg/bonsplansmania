## Comment profiter correctement d'un code Lookfantastic ?

1. Ouvrez la page de l'offre correspondant au code.
2. Ajoutez uniquement les produits signalés comme éligibles.
3. Saisissez le code dans le panier.
4. Contrôlez le montant réellement déduit avant le paiement.
5. N'additionnez pas deux codes sauf si Lookfantastic indique explicitement qu'ils sont cumulables.

Les prix, les produits et les exclusions peuvent évoluer rapidement. La remise affichée dans le panier reste la référence au moment de la commande.
