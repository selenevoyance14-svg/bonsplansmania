## Test gratuit d'un complément alimentaire pour chat

Une nouvelle **étude d'appétence** recherche des propriétaires de chats pour évaluer gratuitement un **complément alimentaire sous forme de pâte**. Riche en nutriments et en énergie, ce produit est destiné à accompagner la **récupération après l'effort**.

Le test se déroule à domicile pendant **7 jours consécutifs**. Les produits seront envoyés **au plus tard le 2 octobre 2026** et l'étude devra être terminée pour le **21 octobre 2026**. Des **friandises pour chat** seront ajoutées au colis en guise de remerciement.

## Quelles sont les conditions pour participer ?

Pour être éligible, votre chat doit :

- être âgé d'au moins **1 an** ;
- peser au maximum **7,5 kg** ;
- être en **bonne santé** ;
- ne suivre **aucun traitement médical** ;
- ne présenter **aucune allergie alimentaire** ;
- ne pas attendre de chatons et ne pas être en période de lactation ;
- pouvoir suivre le protocole pendant les **7 jours** de l'étude.

Le formulaire de pré-inscription recueille les renseignements nécessaires pour vérifier l'éligibilité de votre animal. Remplir le questionnaire ne garantit donc pas d'être retenu pour recevoir le produit.

## Comment se déroule le test ?

Si votre chat est sélectionné, vous recevrez le complément alimentaire en pâte ainsi qu'un document détaillant le protocole. Chaque jour pendant sept jours, une dose doit être proposée **seule, dans une gamelle ou sur une cuillère**, sans être mélangée à sa nourriture. Vous devrez ensuite observer si votre chat accepte volontiers le produit et transmettre vos réponses selon les consignes communiquées.

Votre chat peut continuer à manger ses **aliments habituels pendant l'étude**. Respectez toutefois précisément les quantités et les modalités indiquées avec le produit afin que les observations restent exploitables.

## Comment pré-inscrire votre chat ?

1. Ouvrez le formulaire officiel de pré-inscription.
2. Renseignez vos coordonnées ainsi que le nombre de chiens et de chats du foyer.
3. Indiquez le nom, l'âge et le poids du chat que vous souhaitez inscrire.
4. Confirmez qu'il respecte tous les critères de santé demandés.
5. Choisissez si vous souhaitez ou non un entretien téléphonique pour valider l'inscription.
6. Envoyez le questionnaire puis attendez la confirmation avant de considérer votre chat comme sélectionné.
