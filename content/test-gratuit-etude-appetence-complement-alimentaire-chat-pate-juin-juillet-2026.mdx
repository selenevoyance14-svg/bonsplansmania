## Test gratuit d'un complément alimentaire pour chat

Une nouvelle **étude d'appétence** recherche des propriétaires de chats pour évaluer gratuitement un **complément alimentaire sous forme de pâte**. Riche en nutriments et en énergie, ce produit est destiné à accompagner la **récupération après l'effort**.

Le test se déroule à domicile pendant **7 jours**. Les produits seront envoyés **au plus tard le 7 septembre 2026** et l'étude devra être terminée pour le **26 septembre 2026**.

## Quelles sont les conditions pour participer ?

Pour être éligible, votre chat doit :

- être âgé d'au moins **1 an** ;
- être en **bonne santé** ;
- pouvoir suivre le protocole pendant les **7 jours** de l'étude.

Le formulaire de pré-inscription recueille les renseignements nécessaires pour vérifier l'éligibilité de votre animal. Remplir le questionnaire ne garantit donc pas d'être retenu pour recevoir le produit.

## Comment se déroule le test ?

Si votre chat est sélectionné, vous recevrez le complément alimentaire en pâte ainsi que les instructions nécessaires. Pendant la période d'évaluation, vous devrez observer si votre chat accepte volontiers le produit et transmettre vos réponses selon le protocole communiqué.

Votre chat peut continuer à manger ses **aliments habituels pendant l'étude**. Respectez toutefois précisément les quantités et les modalités indiquées avec le produit afin que les observations restent exploitables.

## Comment pré-inscrire votre chat ?

1. Ouvrez le formulaire officiel de pré-inscription.
2. Renseignez les informations demandées sur votre chat.
3. Vérifiez qu'il a au moins un an et qu'il est en bonne santé.
4. Envoyez le questionnaire pour permettre l'étude de son éligibilité.
5. Attendez la confirmation avant de considérer votre chat comme sélectionné.
