## Mode d'emploi rapide

### Cuisson du riz (à la perfection)

1. **Mesure le riz** avec le **verre doseur** (1 dose = 1 portion)
2. **Rince le riz** sous l'eau froide (sauf riz parfumé / sushi)
3. **Verse le riz** dans le bol antiadhésif
4. **Ajoute l'eau** : 1,5 dose d'eau pour 1 dose de riz (basmati) — voir notice pour autres riz
5. **Pose le couvercle**, branche, **appuie sur le bouton**
6. **Voyant lumineux** : cuisson en cours
7. **Bascule auto** en maintien au chaud quand cuit (10-25 min selon riz)
8. **Sers** avec la cuillère fournie

### Cuisson vapeur (légumes + poisson)

1. **Riz dans le bol** + eau
2. **Légumes / poisson dans le panier vapeur** (au-dessus)
3. Lance la cuisson : **tout cuit en même temps**
4. **15-20 min** : repas complet prêt

### Mode mijoteuse

- Soupes, dahl, tajine léger
- **Mode "cook"** + temps prolongé
- **300 W** = cuisson lente, pas de risque de brûler
