## Comment fonctionne le cashback Poulpeo ?

**Poulpeo** permet de récupérer une partie du montant de certains achats effectués chez ses marchands partenaires. Le gain peut prendre la forme d'un pourcentage ou d'un montant fixe et dépend des conditions établies par chaque enseigne.

Ces offres étaient temporaires et ne doivent plus être présentées comme des promotions actuelles. Le seul taux fiable est celui affiché par Poulpeo **au moment où tu actives le cashback**.

## Que vérifier avant l'achat ?

Un marchand peut proposer plusieurs taux selon le rayon ou le profil de l'acheteur. Avant de commander, vérifie :

- le **taux ou montant actuellement proposé** ;
- les catégories de produits éligibles ;
- les conditions réservées aux nouveaux clients ;
- le montant minimum éventuel de la commande ;
- la compatibilité du cashback avec un code promo ;
- les exclusions concernant les cartes-cadeaux, abonnements ou vendeurs tiers ;
- le délai estimé d'apparition et de validation du gain.

## Qu'est-ce qu'un cashback boosté ?

Un cashback boosté est une augmentation temporaire du taux habituel. Il peut être intéressant pour un achat déjà prévu, mais sa durée et son périmètre sont souvent limités. La présence d'un boost ne signifie pas forcément que le marchand propose le meilleur prix final.

Avant de choisir, compare toujours :

- le prix du produit chez plusieurs vendeurs ;
- les frais de livraison ;
- les réductions immédiatement applicables ;
- le montant réellement récupérable en cashback ;
- les conditions de retour et de garantie.

## Les erreurs qui peuvent empêcher le suivi

Le cashback repose sur le suivi du clic et de la commande. Pour limiter les refus ou les achats non détectés :

- désactive temporairement les bloqueurs de publicité trop stricts ;
- accepte les cookies nécessaires au suivi ;
- vide ton panier avant l'activation lorsque les conditions le demandent ;
- n'ouvre pas un autre comparateur ou site de coupons après avoir activé Poulpeo ;
- utilise uniquement un code promo annoncé comme compatible ;
- évite de changer de navigateur ou d'appareil pendant la commande ;
- ne modifie pas la commande après son enregistrement sans vérifier les conséquences.

## Peut-on cumuler cashback et code promo ?

Le cumul est parfois possible, mais il n'est jamais automatique. Un code trouvé sur un autre site peut réduire immédiatement la facture tout en annulant l'éligibilité au cashback. Il faut donc se référer à la liste des codes acceptés sur la fiche Poulpeo du marchand.

Pour trouver l'option la plus rentable, calcule le prix final avec le code seul, avec le cashback seul, puis avec les deux lorsqu'un cumul est explicitement autorisé.
