## Comment bien utiliser les codes

Le code **SPORT30** est le plus généreux (30€ offerts) mais il est limité aux catégories sport : glisse urbaine, matériel de sport, montres connectées et bracelets connectés. Attention, seulement **120 coupons disponibles** sur toute la durée de l'opération, premier arrivé premier servi.

Le code **APP20** est plus large mais fonctionne **uniquement sur l'application mobile** Rakuten. 20€ offerts dès 159€, c'est idéal pour un achat tech comme l'iPhone 17e ou le MacBook.

Le code **JOUET15** (15€ dès 79€) et **SPORT7** (7€ dès 49€) sont parfaits pour les petits paniers.

En plus des codes, les membres du **Club R** cumulent du cashback sur chaque achat (1% en standard). Les deux se cumulent.

## Ce qu'il faut savoir

- SPORT30 est limité à 120 utilisations au total — ça peut partir vite
