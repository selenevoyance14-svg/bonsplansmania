## Comment fonctionne le code IMBACK ?

Le code **IMBACK** ne retire pas automatiquement 50 % sur tout le catalogue. Il donne accès à des remises pouvant atteindre ce niveau sur les références incluses dans la campagne. Le pourcentage et le prix final dépendent donc du produit, de sa variante et du stock disponible.

Prozis précise également les conditions suivantes :

- le code est limité à **trois utilisations par client** ;
- il n'est **pas cumulable avec les autres promotions en cours** ;
- le montant maximal de réduction est fixé à **300 €** ;
- l'offre reste soumise aux stocks disponibles.

## BONSMANIA : l'alternative à -10 %

Le code partenaire **BONSMANIA** permet d'obtenir **10 % de réduction sur les produits éligibles**, selon les conditions affichées par Prozis. Comme les codes ne sont pas annoncés comme cumulables, comparez le total obtenu avec `IMBACK` et `BONSMANIA`, puis conservez le plus avantageux pour votre panier.

### Comment appliquer le bon code ?

1. Ouvrez Prozis avec le bouton de cette page.
2. Ajoutez les références et les variantes souhaitées au panier.
3. Saisissez **IMBACK** dans le champ consacré au code promotionnel.

5. Vérifiez la réduction, le cadeau éventuel et les frais de livraison avant de payer.
