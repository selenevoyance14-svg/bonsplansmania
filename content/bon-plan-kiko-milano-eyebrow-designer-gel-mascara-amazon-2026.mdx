## Comment appliquer le KIKO Eyebrow Designer ?

1. Brossez les sourcils dans le sens de la pousse.
2. Utilisez la mini-brosse pour les modeler progressivement.
3. Retirez l'excédent de produit avant une seconde application.
4. Laissez sécher sans toucher les sourcils.

Le gel peut être utilisé seul pour discipliner les poils ou après un crayon à sourcils pour fixer le résultat.
