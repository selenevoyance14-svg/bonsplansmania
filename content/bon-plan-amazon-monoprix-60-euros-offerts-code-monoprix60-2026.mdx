## Le code MONOPRIX60 n’est plus valable

L’offre **Amazon Monoprix à 60 € offerts** est désormais terminée. Le règlement officiel précisait que le code **MONOPRIX60** était uniquement valable sur les commandes passées **jusqu’au 6 avril 2026 inclus**.

![Bannière Amazon Monoprix annonçant 60 euros offerts avec le code MONOPRIX60](/images/articles/amazon-monoprix-monoprix60-60-euros-offerts-2026.jpg)

Le service de courses Monoprix reste accessible sur Amazon, mais cette ancienne réduction ne doit plus être saisie au moment du paiement.

[**Voir les courses Monoprix disponibles sur Amazon**](/go/amazon-monoprix-courses)

## Comment fonctionnait l’ancienne offre ?

Le code permettait aux nouveaux clients Monoprix éligibles de bénéficier de **trois remises de 20 €**, soit **60 € d’économies au total**.

| Avantage proposé | Anciennes conditions |
|---|---|
| Réduction totale | 60 € répartis sur trois commandes |
| Remise par commande | 20 € |
| Minimum d’achat | 80 € par commande, hors frais éventuels |
| Code à saisir | MONOPRIX60 lors de la première commande |
| Éligibilité | Membres Amazon Prime n’ayant encore jamais commandé chez Monoprix via Amazon |

Après la première utilisation du code, les deux remises suivantes devaient s’appliquer automatiquement aux commandes éligibles.

## Les conditions importantes à retenir

- L’offre était limitée à **trois commandes Monoprix par client et par compte**.
- Chaque commande devait atteindre au moins **80 € d’achat**.
- La livraison concernait uniquement la **France métropolitaine**.
- Les frais de livraison et d’emballage cadeau n’entraient pas dans le minimum demandé.
- L’avantage était soumis aux stocks disponibles et réservé aux clients répondant aux conditions Amazon Prime.
