## Deux tests produits ACM ouverts jusqu'au 9 avril

Le laboratoire dermatologique **ACM** lance deux nouvelles campagnes ambassadeurs en ce moment. Tu peux postuler pour recevoir gratuitement soit le **Sérum Boréade** seul, soit le **duo Boréade Sérum + Azéane Crème**. Les candidatures ferment le **9 avril 2026**.

---

## Les deux tests disponibles

### 1. Sérum Boréade seul

Le **Boréade Sérum** est un concentré anti-imperfections formulé par ACM. Il contient **97% d'ingrédients d'origine naturelle** et cible les peaux à tendance acnéique :

- Réduit les imperfections et les boutons
- Resserre les pores
- Régule l'excès de sébum
- Texture sérum légère qui pénètre rapidement

### 2. Duo Boréade Sérum + Azéane Crème

Le deuxième test combine le sérum avec la **Crème Azéane**, un soin hydratant et réparateur. Le duo forme une routine complète :

- **Boréade Sérum** le soir pour traiter les imperfections
- **Azéane Crème** le matin pour hydrater, apaiser et protéger la peau

L'Azéane est connue pour son action réparatrice sans effet gras, idéale pour les peaux mixtes à grasses qui ont besoin d'hydratation sans surcharger.

## Comment participer

1. Rendez-vous sur la **page ambassadeur ACM**
2. Choisissez le test qui vous intéresse (Sérum seul ou duo Sérum + Crème)
3. Remplissez le formulaire de candidature
4. Si vous êtes sélectionnée, vous recevez les produits gratuitement chez vous
5. Partagez votre avis après utilisation

Candidatures ouvertes **jusqu'au 9 avril 2026**.
