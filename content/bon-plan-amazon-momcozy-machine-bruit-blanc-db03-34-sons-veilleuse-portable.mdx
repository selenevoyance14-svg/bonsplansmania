Concrètement :
- **Bébé pleure ?** → bruit blanc → apaisement en 2-5 min *(marche 8 fois sur 10)*

- **Sieste dans une pièce non-calme ?** → bruit blanc crée une bulle sonore

Ça marche aussi pour **les adultes** *(concentration, sommeil, méditation)*.

## Comment l'utiliser

1. **Recharge** la batterie *(1-2 h pour charge complète)*
2. **Télécharge l'app Momcozy** *(iOS / Android)* — facultatif mais recommandé
3. **Choisis le son** *(via boutons ou app)* — commence par bruit blanc classique
4. **Ajuste le volume** — doit être **plus fort** que les pleurs de bébé au début, puis baisser
5. **Choisis la veilleuse** *(couleur + intensité)*
