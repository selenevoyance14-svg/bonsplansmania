## Notre avis mode par mode

### Air Shot — le mode qui surprend

C'est le premier mode qu'on a teste et honnêtement, la premiere fois ca fait bizarre. On ressent des micro-picotements sur la peau, un peu comme des petites aiguilles. Rien de douloureux mais c'est surprenant.

On a commence a l'intensite 1 et on est montees progressivement. Apres quelques seances, la peau semble plus lisse, les pores un peu moins visibles. C'est le mode qu'on utilise le plus souvent.

**Notre note : on valide.** C'est efficace sur les pores et la texture de peau.

### Booster — le meilleur mode pour les serums

Ce mode aspire legerement la peau pour faire penetrer les actifs en profondeur. On l'utilise avec un [serum a l'acide hyaluronique](/article/test-pourquoi-utiliser-serum-visage-routine-soin-meilleurs-serums-amazon-2026) et la difference se sent : la peau absorbe tout, elle est repulpee apres la seance.

Par contre, sur le front ca peut etre un peu desagreable — une sensation d'aspiration etrange. On evite cette zone et on se concentre sur les joues et le menton.

**Notre note : tres bien**, surtout combine avec un bon serum.

### MC (Microcourant) — le mode anti-rides

Le microcourant stimule les muscles du visage et la production de collagene. C'est le mode le plus subtil — on ne ressent presque rien pendant la seance, mais apres quelques semaines, on a note que la peau semble plus ferme le matin.

Il faut utiliser une creme ou un gel conducteur pour que ca glisse bien. C'est d'ailleurs le point noir : trouver le bon produit de glisse n'est pas toujours evident. On a fini par utiliser de l'aloe vera gel et ca marche bien.

**Notre note : bien**, mais patience requise pour les resultats.

### Derma Shot — le mode tonifiant

C'est le mode le plus intense. Il tonifie les muscles du visage avec des micro-impulsions. On l'utilise 2 a 3 fois par semaine maximum. C'est celui qui donne le plus un effet "lifting" immediat apres la seance.

**Notre note : impressionnant** sur le moment, a confirmer sur le long terme.
