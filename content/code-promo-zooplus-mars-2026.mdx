## PURINA25 : 25 % sur Felix, Gourmet et Purina ONE

Ce code remplace les anciens coupons séparés pour Gourmet et Felix. Il s’adresse **uniquement aux nouveaux clients Zooplus** et concerne les produits des trois marques annoncées : **Felix, Gourmet et Purina ONE**.

Comparez les formats avant d’acheter : pour des croquettes, regardez le prix au kilo ; pour des sachets ou conserves, comparez aussi le poids de chaque portion. Un lot plus volumineux n’est intéressant que si votre animal le consomme habituellement et si vous pouvez le conserver correctement.

## WELCOMEMARS : 20 % sur Dreamies, même si vous êtes déjà client

**WELCOMEMARS** est ouvert à **tous les clients** sur les produits **Mars Dreamies** concernés. C’est donc le code de cette sélection à regarder si vous avez déjà passé commande chez Zooplus.

L’offre annoncée concerne Dreamies : elle ne signifie pas que toutes les marques du groupe Mars bénéficient de la même remise.

## NEWHILLS20 : 20 % sur Hill’s Science Plan

Les nouveaux clients peuvent utiliser **NEWHILLS20** pour obtenir **20 % sur Hill’s Science Plan**. Ne confondez pas cette gamme avec les autres gammes Hill’s : l’offre communiquée porte sur **Science Plan**.

Choisissez une référence adaptée à l’âge et aux besoins habituels de votre animal. Le pourcentage de remise ne doit pas être le seul critère de choix.

En France métropolitaine, la grille officielle indique la **livraison offerte en point relais au-dessus de 39 €**, selon le réseau et les conditions applicables.
