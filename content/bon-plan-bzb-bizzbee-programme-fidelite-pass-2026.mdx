## Le BZB Pass — programme fidélité gratuit

**BZB** (Bizzbee), la marque française de mode homme et femme, propose un **programme de fidélité 100% gratuit** et dématérialisé : le **BZB Pass**. Cumulez des points à chaque achat et débloquez des avantages exclusifs.

**Bonus** : **20 points offerts** dès l'inscription sur l'application !

## Comment ça marche

| | |
|---|---|
| **1€ dépensé** | = **1 point** cumulé |
| **Missions hebdo** | Points bonus supplémentaires |
| **Inscription** | Gratuite et dématérialisée |
| **Accès** | Application BZB ou compte client web |
| **Bonus inscription** | **20 points offerts** |

## Les 3 paliers

### Starter (0-100 points)

- 🎂 **Offre anniversaire** personnalisée
- 🎰 Accès à la **loterie BZB** (lots surprises)

### Explorer (100-300 points)

- 🎫 **Bons d'achat de 12€**
- 🎯 Nouvelles **missions** pour gagner plus de points
- + tous les avantages Starter

### Traveler (300+ points)

- 🏷️ **-25% sur un ticket** par an
- 🎪 Accès **VIP aux événements** privés BZB
- + tous les avantages Explorer

## Les avantages en détail

| Avantage | Palier |
|----------|--------|
| Offre anniversaire | Dès Starter |
| Loterie BZB | Dès Starter |
| Bons d'achat 12€ | Dès Explorer |
| Missions bonus | Dès Explorer |
| -25% sur un ticket/an | Traveler |
| Événements VIP | Traveler |

## Bon à savoir

- ✅ Un **palier atteint reste acquis** même après utilisation des points
- ✅ Points et palier valables **2 ans** (à condition de cumuler au moins 1 point)
- ✅ Si vous aviez l'ancien programme **Fid'move**, vos points sont **transférés automatiquement**
- ✅ Accessible sur **l'appli BZB** — tout est dématérialisé
