## Ce qu'on sait sur les lots

Le lot principal est un **abonnement bien-etre d'un an** : chaque mois, le gagnant choisit une activite parmi une selection (spa, massages, sport, detente...). Pour les autres participants, ce sont des **bons de reduction** sur les produits Lactel qui sont offerts. Comme c'est un jeu **100% gagnant**, tout le monde repart avec quelque chose.
