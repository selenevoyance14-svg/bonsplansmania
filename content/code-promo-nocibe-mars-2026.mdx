## FAQ - Codes promo Nocibe

**Les codes MARS25, ROUTINE25 et 25PRINTEMPS sont-ils cumulables ?**
Non, un seul code promo peut etre applique par commande. Testez les trois pour voir lequel vous offre la meilleure reduction selon votre panier.

**Le code POCHONAPP est-il cumulable avec un code de reduction ?**
Generalement non. Le code POCHONAPP offre un cadeau (sac surprise) et ne peut pas etre combine avec un code de reduction. Choisissez entre le cadeau et la remise.

**Comment s'inscrire au programme fidelite Nocibe ?**
L'inscription est gratuite et se fait en magasin ou sur nocibe.fr. Vous recevez une carte de fidelite numerique qui cumule vos points a chaque achat.

**Les produits outlet sont-ils des contrefacons ?**
Non, absolument pas. Les produits de l'outlet Nocibe sont 100% authentiques. Ce sont des fins de series, des editions limitees ou des produits dont le packaging a ete modifie.

**Peut-on utiliser un code promo en magasin ?**
Certains codes sont exclusivement en ligne (comme POCHONAPP qui est reserve a l'appli). Les codes mentionnant "en ligne" ou "sur le site" ne fonctionnent pas en magasin. Verifiez les conditions de chaque code.

**Quelle est la politique de retour Nocibe ?**
Nocibe accepte les retours sous 30 jours apres reception pour les produits non ouverts. En magasin, les conseillers peuvent egalement vous aider pour un echange.

**La livraison gratuite des 60€ s'applique-t-elle apres reduction ?**
Oui, le seuil de livraison gratuite est calcule sur le montant apres application du code promo. Assurez-vous que votre total apres reduction depasse toujours les 60€.
