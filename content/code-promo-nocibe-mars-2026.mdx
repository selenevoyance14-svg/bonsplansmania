## Les trois codes promo Nocibé encore valables aujourd'hui

Nocibé propose trois codes différents jusqu'au **17 août 2026**. Ils sont réservés aux membres du programme de fidélité ou aux personnes qui souscrivent une carte Nocibé.

| Code | Avantage | Où l'utiliser ? | Fin |
|---|---|---|---|
| **30APPSUMMER** | **−30 % dès 99 € d'achat** | Application Nocibé uniquement | 17 août 2026 |
| **HOLIDAY25** | **−25 % dès 89 € d'achat** | Site et application | 17 août 2026 |
| **COFFR10** | **−10 % supplémentaires** sur une sélection de coffrets déjà remisés à −30 % | Site, application et boutiques participantes | 17 août 2026 |

## Code 30APPSUMMER : −30 % dès 99 € sur l'application

Le code **30APPSUMMER** offre **30 % de réduction dès 99 € d'achat**, uniquement dans l'application Nocibé. Il peut être utilisé une seule fois pendant l'opération.

Cette offre est la plus forte en pourcentage, mais elle nécessite le panier le plus élevé et ne fonctionne pas sur le site classique.

## Code HOLIDAY25 : −25 % dès 89 €

Le code **HOLIDAY25** permet d'obtenir **25 % de réduction dès 89 € d'achat** sur nocibe.fr et dans l'application. Il est utilisable une fois jusqu'au 17 août.

Pour un panier compris entre 89 € et 98,99 €, il est plus accessible que 30APPSUMMER. À partir de 99 €, comparez directement les deux codes dans l'application.

## Code COFFR10 : remise supplémentaire sur les coffrets

Le code **COFFR10** apporte **10 % de réduction supplémentaires** sur une sélection de coffrets déjà remisés à 30 %. Sur le site et l'application, le code doit être saisi au panier. Dans les boutiques participantes, la remise est appliquée en caisse.

L'offre vise uniquement les coffrets signalés et reste soumise aux stocks disponibles.

## Les principales exclusions

Les trois offres sont non cumulables avec les autres promotions et les chèques fidélité. Selon le code choisi, les exclusions comprennent notamment :

- les produits « Petits prix », « Prix Web », « Prix Nocibé » et « Points Rouges » ;
- les produits Outlet et Soldes ;
- les cartes cadeaux, cartes Institut et prestations Institut ;
- les produits partenaires et emballages payants ;
- pour COFFR10, plusieurs marques et références exclues sont détaillées dans les conditions de l'offre.

La remise réellement applicable doit toujours être vérifiée dans le panier avant le paiement.

## Prix Web et Points Rouges : pourquoi le code ne fonctionne pas ?

Les articles signalés **« Prix Web »** bénéficient déjà d'un tarif réservé au site et à l'application. Ils ne peuvent recevoir aucune remise supplémentaire.

Les articles marqués d'un **point rouge** sont eux aussi exclus des codes promotionnels et des chèques fidélité Nocibé.

## Comment utiliser un code promo Nocibé

1. Connectez-vous à votre compte fidélité Nocibé ou souscrivez une carte.
2. Ajoutez les produits éligibles au panier.
3. Vérifiez que le seuil de 89 € ou 99 € est atteint si nécessaire.
4. Saisissez **HOLIDAY25**, **30APPSUMMER** ou **COFFR10**.
5. Contrôlez la remise avant de valider la commande.

## Quel code choisir ?

- choisissez **HOLIDAY25** si votre panier atteint 89 € mais reste inférieur à 99 € ;
- testez **30APPSUMMER** dans l'application dès 99 € d'achat ;
- utilisez **COFFR10** si votre panier contient un coffret éligible déjà remisé à 30 %.
