## 5 000 sacs banane Pitch à gagner en août

**Pitch Brioche Pasquier** organise un jeu avec obligation d'achat du **8 juillet au 31 octobre 2026**. En août, **5 000 sacs banane Pitch** sont mis en jeu par instants gagnants.

Pour tenter sa chance, il faut acheter un produit Pitch participant et utiliser le **code unique présent sur le dépliant inséré dans le sachet**. Conserve bien la preuve d'achat originale.

[Participer au jeu Pitch](https://www.jeu-pitch.briochepasquier.com/)

## Le concours en bref

| Information | Détail |
|---|---|
| **Organisateur** | Brioche Pasquier — marque Pitch |
| **Période d'achat** | Du **8 juillet au 31 octobre 2026** |
| **Mécanique** | Instants gagnants |
| **Condition** | Achat d'un produit Pitch participant |
| **Code demandé** | Code unique inséré dans le sachet |
| **Lot d'août** | **5 000 sacs banane** |
| **Fin du jeu** | **31 octobre 2026** |

## Tous les sacs mis en jeu

Le site officiel annonce **18 000 sacs** répartis sur quatre mois :

- **juillet : 3 000 sacs cordelette** ;
- **août : 5 000 sacs banane** ;
- **septembre : 6 000 sacs à dos** ;
- **octobre : 4 000 sacs de sport**.

Les visuels sont présentés comme non contractuels par l'organisateur.

## Comment participer ?

1. Achète un produit **Pitch** participant entre le 8 juillet et le 31 octobre 2026.
2. Conserve le ticket de caisse ou la preuve d'achat originale.
3. Récupère le code unique figurant sur le dépliant placé dans le sachet.
4. Ouvre le [site du jeu Pitch](https://www.jeu-pitch.briochepasquier.com/).
5. Crée ton compte ou connecte-toi.
6. Saisis ton code puis lance l'instant gagnant.

Un produit acheté donne **une chance de gagner**. En cas d'échec, il faut saisir un nouveau code unique pour rejouer.

## En cas de gain

Le site indique que le sac est envoyé sous **8 à 10 semaines** dans le point relais Colissimo sélectionné par le gagnant. Garde impérativement l'emballage, le code et la preuve d'achat jusqu'à la réception du lot.

Ce jeu nécessite un achat. Notre lien vers l'opération n'est pas affilié.
