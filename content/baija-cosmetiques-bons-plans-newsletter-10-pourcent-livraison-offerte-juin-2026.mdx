## Baïja Joy Club, comment fonctionne le programme de fidélité ?

Le **Baïja Joy Club** complète l’offre newsletter. L’inscription au programme est annoncée avec **20 points de bienvenue**. Les avantages et le nombre de points nécessaires pour obtenir une récompense peuvent évoluer : consultez toujours la page du programme de fidélité avant de valider une commande.

L’inscription à la newsletter et l’adhésion au programme de fidélité sont deux démarches distinctes. La première permet de recevoir l’offre de bienvenue, tandis que la seconde sert à cumuler des points sur les achats éligibles.

## Comment obtenir les 10 % chez Baïja ?

1. Rendez-vous sur le site officiel Baïja.
2. Inscrivez votre adresse e-mail dans le formulaire de newsletter.
3. Confirmez l’inscription si un message de validation est envoyé.
4. Récupérez le code de réduction reçu par e-mail.
5. Saisissez-le dans le champ prévu au panier avant de commander.

Si le message n’arrive pas, vérifiez les courriers indésirables et les onglets réservés aux promotions. Le code peut être réservé aux nouveaux clients et exclure certains produits ou offres déjà remisées.
