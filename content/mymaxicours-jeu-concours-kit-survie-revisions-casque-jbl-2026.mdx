## Le lot à gagner

Un **kit de survie spécial révisions** comprenant :

- **Casque audio JBL** — pour se concentrer sans distractions
- **Surligneurs** — pour annoter ses cours efficacement
- **Annales** — pour s'entraîner sur les sujets d'examen
- **Timer** — pour organiser ses sessions de révision
- **Planning de révisions** — pour structurer son programme

Tout ce qu'il faut pour aborder les examens sereinement.

## Comment participer

1. **Rendez-vous sur la page myMaxiboost**
2. **Entrez votre adresse email**
3. **Indiquez si vous êtes parent ou élève**
4. **Validez votre participation** — quelques secondes suffisent

Participation ouverte aux majeurs ou aux mineurs avec autorisation parentale.
