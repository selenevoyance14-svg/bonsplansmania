## Comment fonctionnent les offres iGraal ?

**iGraal** permet de récupérer une partie du montant de certains achats en ligne sous forme de cashback. La plateforme propose aussi des **codes promo**, des offres temporaires et, selon les périodes, des taux renforcés chez des marchands comme Samsung, Smartbox ou d'autres enseignes partenaires.

## Vérifier une offre avant de commander

Avant de passer commande, contrôle ces informations sur la page iGraal du marchand :

- le **taux de cashback** ou le montant fixe proposé ;
- les catégories de produits éligibles ;
- les éventuelles exclusions concernant les produits neufs, reconditionnés ou vendus par un tiers ;
- la compatibilité entre le cashback et le code promo utilisé ;
- le montant minimum de commande ;
- les conditions réservées aux nouveaux clients ;
- le délai moyen de validation annoncé.

Un taux élevé ne s'applique pas nécessairement à l'ensemble du site marchand. Certaines catégories peuvent bénéficier d'un taux différent ou ne donner droit à aucun remboursement.

## Les erreurs qui peuvent annuler le cashback

Le suivi peut échouer si le parcours d'achat est interrompu. Pour limiter ce risque :

- désactive temporairement les bloqueurs de publicité et les protections anticookies trop strictes ;
- accepte les cookies nécessaires sur iGraal et chez le marchand ;
- évite d'ouvrir d'autres comparateurs ou sites de codes promo après l'activation ;
- n'utilise qu'un code promo annoncé comme compatible par iGraal ;
- termine l'achat dans la même session et le même navigateur ;
- vide le panier avant l'activation si les conditions du marchand l'exigent ;
- évite de modifier la commande après son enregistrement.

## Cashback et code promo : peut-on cumuler les deux ?

Oui, mais uniquement si le code est accepté dans les conditions de l'offre iGraal. Un code trouvé ailleurs peut fonctionner au paiement tout en rendant le cashback inéligible. Le meilleur calcul consiste donc à comparer :

- le prix final avec le code promo ;
- le prix final avec le cashback ;
- le cumul des deux lorsqu'il est explicitement autorisé.

## Samsung, Smartbox ou Lidl : pourquoi les taux diffèrent-ils ?

Chaque marchand fixe ses propres règles. Le cashback peut varier selon le type de client, le rayon, la référence achetée ou la campagne commerciale. Chez un même marchand, un smartphone, un accessoire et un produit reconditionné peuvent ainsi avoir trois conditions différentes.

Les offres présentées comme un **boost** sont généralement temporaires. Elles doivent être vérifiées au moment de la commande et ne doivent pas être considérées comme des taux permanents.
