## Quel code promo sur les packs Isinwheel ?

La page affiche le code **BU8**, présenté comme une **réduction supplémentaire de 8 % sur les packs**. Il est indiqué pour les offres groupées, **pas pour l’ensemble du catalogue**. Vérifiez son éligibilité, son cumul éventuel avec les prix soldés et le total obtenu dans le panier avant de commander.

## Comment choisir une offre ?

Comparez d’abord le **modèle exact**, la variante et les accessoires inclus : une fiche peut proposer plusieurs puissances ou couleurs à des prix différents. Consultez ensuite l’autonomie dans ses conditions de mesure et le poids de l’engin. Enfin, si vous souhaitez circuler sur voie publique en France, vérifiez sa conformité : [la Sécurité routière rappelle la limite de 25 km/h pour les engins de déplacement personnel motorisés](https://www.securite-routiere.gouv.fr/sites/default/files/2026-05/nv_dsr_depliant_edpm-exe_bd.pdf). Une trottinette affichant une vitesse bien supérieure ne doit pas être présumée utilisable sur route.
