## SUPER ou BONSMANIA : quel code choisir ?

Le code partenaire **BONSMANIA** offre **10 % sur les références éligibles**. Il constitue une autre option pour vos achats Prozis. **Ne comptez pas sur un cumul avec SUPER**, dont les conditions excluent les autres promotions en cours.

1. Accédez à la boutique depuis l’un des liens de cette sélection.
2. Choisissez vos produits, formats et parfums.
3. Essayez **SUPER** et consultez le total ainsi que les cadeaux disponibles.
4. Si vous souhaitez comparer avec **BONSMANIA**, remplacez le code et vérifiez le nouveau récapitulatif.
5. Conservez l’option la plus intéressante pour votre panier et contrôlez les éventuels frais de livraison.

N’ajoutez pas des produits inutiles uniquement pour atteindre un cadeau : comparez la dépense supplémentaire à son intérêt pour vous.
