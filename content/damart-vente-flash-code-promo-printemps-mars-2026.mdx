Le **Black Friday Damart** annonce **jusqu’à −60 % sur une sélection en ligne**, jusqu’au **30 novembre 2026**. En boutique, la remise maximale annoncée est de 50 %. Des codes avantage distincts permettent aussi d’économiser sur des articles éligibles : comparez les conditions avant de choisir.

## Les offres à comparer

| Avantage | Conditions principales |
| --- | --- |
| Black Friday | Jusqu’à **−60 % en ligne**, sur les articles signalés ; fin le **30 novembre** |
| Code de réduction | **30 € dès 100 €** d’achats éligibles, jusqu’au **5 janvier 2027** |
| Code de livraison | Relais offert dès **70 € après remises**, jusqu’au **5 janvier 2027** |
| Newsletter | **15 € dès 40 €**, jusqu’au **31 mars 2027**, après inscription et selon exclusions |

Les codes de réduction excluent notamment les prix barrés, points rouges et offres « Atouts prix ». Ils sont utilisables une fois et non cumulables avec d’autres réductions ou promotions. Le code de livraison constitue une offre distincte : ne présumez pas de son cumul avec la remise de 30 €.

## Où récupérer le code adapté ?

Sur le site Damart, consultez la page « Code promo Damart », puis choisissez l’avantage et cliquez sur **« Copier le code »**. Saisissez-le dans le champ **« Code avantage »** du panier. Contrôlez les produits éligibles, le seuil après remise quand il s’applique et les frais avant de payer.

## Thermolactyl et vêtements de saison

Pour un vêtement Thermolactyl, comparez les niveaux de chaleur, les matières et les tailles sur sa fiche. Un article déjà remisé peut être exclu du code : le meilleur repère reste le **total final livré**, et non l’addition des pourcentages et avantages annoncés.

## Retrait en boutique et retours

Damart annonce la **livraison en boutique gratuite dès 19 €**, et facturée 3 € en dessous. Les conditions indiquent également des **retours gratuits pendant 60 jours** pour l’opération annoncée du **20 novembre au 6 décembre 2026**, au lieu de 30 jours habituellement. Consultez les modalités de retour avant commande.
