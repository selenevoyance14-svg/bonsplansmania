## 🌿 Le coffret : Rituel Régénérant Marilou Bio

### Le concept

Le **Coffret Rituel Régénérant Marilou Bio** est conçu spécialement pour la **Fête des Mères 2026** : une **routine simple jour + nuit** pour offrir à sa maman (ou pour soi-même) un **soin régénérant bio** complet.

### Les 2 soins inclus

1. 🌅 **Crème de jour régénérante**
   - Action **hydratante** + **protectrice** journée
   - Texture légère, base maquillage idéale
   - Formule bio certifiée

2. 🌙 **Crème de nuit régénérante**
   - Action **réparatrice nocturne** (la peau se régénère la nuit)
   - Texture plus riche
   - Formule bio certifiée

### Pourquoi Marilou Bio

- 🇫🇷 **Made in France** (atelier Marilou Bio en Vendée)
- 🌱 **Bio certifié** (Cosmébio, Ecocert)
- 🐰 **Cruelty-free** : pas de tests animaux
- 🌍 **Engagement éco** : packaging recyclable, ingrédients d'origine naturelle
- 💧 **Distribution** : site officiel + parapharmacies + Naturalia
- 🎁 **Format coffret** : présentation cadeau Fête des Mères

### Pour qui c'est idéal

- 💄 **Créateur·rices TikTok beauté / lifestyle** : c'est une **mission influence**, pas un test produit classique
- 🌿 **Adeptes du bio / made in France** : profil cohérent avec la marque
- 👩 **Femme 30-55 ans** : ciblage Marilou Bio
- 🎁 **Maman / fille / belle-fille** qui veut offrir un cadeau Fête des Mères

## 🎥 La spécificité : c'est une mission TikTok (pas un test classique)

⚠️ **Différence importante** : Cette opération n'est pas un test produit gratuit classique. C'est une **mission d'influence TikTok** : tu reçois le produit **en échange de la création d'une vidéo TikTok** sur ton expérience.

### Ce que ça implique

- 🎥 **Tu dois avoir un compte TikTok actif** : Marilou Bio sélectionne sur la qualité du profil créateur
- 📊 **Engagement requis** : pas besoin d'être influenceur·euse pro, mais un compte avec **abonné·es engagé·es** (même 500-2000 abonnés OK si engagement élevé)
- 🎬 **1 vidéo TikTok minimum** : présentation du coffret, démo routine, avis sincère
- 🏷️ **Hashtags + mention** : @mariloubio + #mariloubio + #ad ou #partenariat (transparence FTC)
- ⏰ **Délai de publication** : généralement 2-4 semaines après réception du coffret

### Ce que ça rapporte

- 🎁 **Coffret offert** (~25-40€ valeur retail)
- 📈 **Exposition pour ton compte** : Marilou Bio repartage parfois les vidéos
- 🤝 **Potentiel partenariat long terme** : si ta vidéo marche bien, missions futures possibles
- 💰 **Pas de rémunération directe** sur cette mission (c'est un échange produit/contenu)

## Comment candidater à la Mission Influence

### Étape par étape

1. **Clique** sur [la page ambassadeur Marilou Bio](https://www.mariloubio.com/fr/content/20-devenir-ambassadeur)
2. **Crée ton compte Marilou Bio** (gratuit) si tu n'es pas membre
3. **Renseigne ton profil** : type de peau, problématique, **lien vers ton compte TikTok** (essentiel pour cette mission)
4. **Postule à la Mission Influence TikTok Coffret Rituel Régénérant**
5. **Attends la sélection** (Marilou Bio évalue ton profil TikTok)
6. **Si tu es sélectionné·e** : tu reçois le coffret + brief de la vidéo
7. **Crée et publie ta vidéo TikTok** dans le délai imparti
8. **Tag** @mariloubio + #mariloubio + mention #ad / #partenariat

### Conseils pour maximiser tes chances

⚠️ **Sélection sur ton profil créateur** : c'est différent d'un test produit aléatoire

- **Lien TikTok actif** : profil à jour, vidéos régulières, engagement (likes/commentaires)
- **Thématique cohérente** : beauté, lifestyle, bio, mom-influencer = profil idéal
- **Bio renseignée** : ton univers visuel doit matcher Marilou Bio (naturel, soft, féminin)
- **Vidéos qualitatives** : pas besoin de matériel pro, mais éclairage + son corrects
- **Pas obligatoire d'être influenceuse pro** : Marilou Bio recrute aussi des **micro-influenceuses** (500-5000 abonné·es) si engagement élevé
