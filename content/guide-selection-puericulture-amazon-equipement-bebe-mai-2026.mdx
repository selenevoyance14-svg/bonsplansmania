## Comment choisir l'équipement bébé essentiel ?

| Catégorie | Indispensable | Budget total moyen |
|---|---|---|
| **Sommeil** | Lit + matelas + lit parapluie + gigoteuse | ~150-300€ |
| **Allaitement / biberons** | Tire-lait + biberons + chauffe-biberon + stérilisateur | ~200-400€ |
| **Repas (4-6 mois)** | Chaise haute + cuiseur mixeur + pots conservation | ~150-300€ |
| **Transport** | Poussette + siège auto + cosy + chancelière | ~250-500€ |
| **Sécurité maison** | Barrière + caches prises + tapis | ~80-150€ |
| **Éveil** | Mobile + jouets éveil + tour d'apprentissage | ~80-200€ |

→ **Total équipement bébé** : entre **900€ et 1900€** selon les choix. **L'occasion** + les **promos Amazon** + les **cadeaux de naissance** peuvent **diviser par 2** ce budget.

---

## Notre conseil global

**Priorise** dans cet ordre pour ne pas te ruiner :

1. **Indispensable jour 1** : **lit + matelas + cosy auto + 6-8 bodies + biberons + tétines**
2. **Avant 3 mois** : **poussette + chauffe-biberon + chancelière + stérilisateur**
3. **Avant 6 mois** : **chaise haute + cuiseur mixeur + pots conservation**
4. **Avant 9 mois** : **lit parapluie + barrière sécurité + sucettes 6+**
5. **Avant 18 mois** : **tour d'apprentissage + nouvelles sucettes 18+ + premier siège auto i-Size**

→ **Évite** d'acheter **avant la naissance** : **transat**, **trotteur**, **marchette**, **pèse-bébé** — tu pourras juger après si tu en as besoin.
