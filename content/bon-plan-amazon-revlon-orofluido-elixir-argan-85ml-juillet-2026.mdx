## Comment utiliser

### Sur cheveux mouillés

1. **Après le shampoing**, essorer les cheveux
2. **Verser 2-3 gouttes** dans les paumes
3. **Réchauffer** puis répartir sur les longueurs et pointes
4. **Coiffer** normalement (brushing, séchage, coiffage)

### Sur cheveux secs

1. **1 goutte** sur les longueurs pour dompter les frisottis
2. **2 gouttes** sur cheveux ternes pour raviver la brillance
3. **Réappliquer** en cours de journée si besoin
