## Le programme Ambassadeur Algologie

La marque française de soins marins **Algologie** propose un **programme Ambassadeur** permettant de candidater à ses campagnes de tests produits. Les personnes sélectionnées reçoivent le ou les soins chez elles, les utilisent pendant **3 semaines**, puis partagent leur avis.

Les campagnes disponibles sont affichées directement dans le module présent sur la page officielle. Leur nombre et les produits proposés peuvent donc changer au fil de l'année.

[**Voir les tests Algologie actuellement disponibles →**](https://www.algologie.com/fr/content/7-testez-nos-produits)

## Comment fonctionne le programme ?

1. Consultez les campagnes affichées sur la page **« Testez nos produits »**.
2. Sélectionnez le test qui vous intéresse et remplissez le formulaire de candidature.
3. Algologie choisit les profils correspondant à la campagne.
4. Si vous êtes retenue, vous recevez gratuitement le ou les produits chez vous.
5. Vous testez les soins pendant **3 semaines**.
6. Vous partagez ensuite un retour d'expérience sincère.

## À savoir avant de candidater

| Élément | Détail |
|---|---|
| **Organisateur** | Algologie |
| **Type d'opération** | Programme Ambassadeur et tests de cosmétiques |
| **Durée annoncée du test** | 3 semaines |
| **Participation** | Gratuite, sur sélection |
| **Produits proposés** | Variables selon les campagnes en cours |
| **Contrepartie** | Tester les soins et partager son avis |

Pour augmenter vos chances, complétez soigneusement votre profil et répondez précisément au questionnaire. L'inscription au programme ne garantit pas de recevoir un produit : chaque campagne possède ses propres critères de sélection.
