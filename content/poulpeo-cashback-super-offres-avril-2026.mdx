## Pourquoi un cashback peut-il être refusé ?

Les causes les plus fréquentes sont faciles à éviter :

- le cashback n’a pas été activé avant la commande ;
- les cookies du marchand ont été refusés ;
- un bloqueur de publicité ou de suivi était actif ;
- un code promo non référencé par Poulpeo a été utilisé ;
- la commande a été passée dans une application non éligible ;
- un autre comparateur ou lien affilié a été ouvert après l’activation ;
- la commande a été annulée, retournée ou modifiée.

Si tu réalises plusieurs commandes successives, réactive le cashback avant chacune d’elles. Dans l’application Poulpeo, reste dans la fenêtre de navigation ouverte après l’activation.
