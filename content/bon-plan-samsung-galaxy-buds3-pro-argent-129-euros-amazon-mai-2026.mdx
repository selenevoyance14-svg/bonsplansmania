## FAQ

**Compatibles avec iPhone ?**

**Oui** en Bluetooth standard (audio + ANC OK), **mais** : pas de **Galaxy AI**, pas de **suivi de tête audio 360**, app Galaxy Wearable indisponible sur iOS. Pour iOS, regarde plutôt les **AirPods Pro 2**.

**Différence avec les Galaxy Buds3 standard ?**

Les **Pro** ont : **ANC contextuelle** plus puissante, **codec audio haute résolution**, **micros bidirectionnels** plus performants pour les appels. Les standards ont une qualité **correcte** mais un cran en dessous sur l'ANC + audio.

**Autonomie ?**

Selon Samsung : **6 heures** d'écoute ANC ON + **20 heures** au total avec le boîtier. **Recharge sans fil** via Qi ou inversée Galaxy.

**Étanchéité ?**

**Certifiés IP57** : résistants à la **transpiration** + **pluie légère**. **Pas conçus** pour la natation.

**Différence Argent vs autre coloris ?**

Aucune différence technique. Juste **esthétique**. L'Argent est **Exclusivité Amazon FR** + **chargeur secteur inclus** (alors que les autres coloris sont vendus sans).

**Mode multipoint ?**

**Oui** : connexion simultanée **2 appareils Galaxy**. Sur appareils non-Galaxy, fonctionnalité limitée.

**Existe-t-il une garantie ?**

**Garantie constructeur Samsung 2 ans** (UE). Possibilité d'étendre via Amazon.

**Latence pour les jeux ?**

**Mode jeu activable** dans Galaxy Wearable → réduit la latence à **environ 60 ms** (correct pour mobile gaming, pas pour eSport compétitif).
