## 💡 Comment choisir son hydratant corps ?

| Critère | À regarder |
|---|---|
| **Type de peau** | Très sèche / sèche / normale / sensible / atopique |
| **Texture** | Lait (léger), crème (épais), baume (très épais) |
| **Actifs clés** | Beurre de karité, acide hyaluronique, glycérine, céramides, niacinamide, urée |
| **Sans parfum ?** | Indispensable si **peau réactive** ou **enfant** |
| **Format** | 200-300 ml (sac/voyage) ou **500-625 ml** (gros format économique) |
| **Tenue** | **24h, 48h ou 72h** d'hydratation (selon la formule) |
| **Origine** | Marque pharmacie / cosmétique conventionnelle / clean naturelle |

→ **Astuce** : applique ton hydratant **sur peau légèrement humide** (sortie de douche) pour **booster l'absorption** et "sceller" l'eau.

## 💡 Bonus : la routine hydratante parfaite

| Étape | Action |
|---|---|
| 1️⃣ **Douche tiède** (pas brûlante) | L'eau chaude lave le film hydro-lipidique |
| 2️⃣ **Savon doux ou syndet** | Évite les gels douche moussants agressifs |
| 3️⃣ **Tampon doux la peau** | Ne pas frotter vigoureusement |
| 4️⃣ **Applique l'hydratant sur peau humide** | Booste l'absorption + scelle l'eau |
| 5️⃣ **Insiste sur les zones sèches** | Coudes, genoux, talons, mollets |
