## Une machine Dolce Gusto NEO Latte offerte

Dolce Gusto propose une offre particulièrement intéressante : pour **12 boîtes NEO éligibles achetées simultanément**, une **machine NEO Latte blanche est ajoutée gratuitement au panier**.

Les boîtes proposées commencent à **4,37€**, soit un panier minimal de **52,44€ pour 12 boîtes** si tu sélectionnes uniquement les références à ce prix. Les tarifs peuvent varier selon les boissons choisies.

[**Profiter de la machine NEO Latte offerte →**](https://www.dolce-gusto.fr/ventes-privees-neo-latte-aout-2026)

## Les conditions de l'offre

- Ajouter **12 boîtes NEO** parmi la sélection de l'opération
- Acheter les 12 boîtes **simultanément dans une même commande**
- La **NEO Latte blanche** est ajoutée automatiquement au panier
- Offre limitée à **une machine offerte par commande**
- Offre valable en France métropolitaine, dans la limite des stocks disponibles
- Offre compatible avec les bons du programme **PREMIO**
- Les Packs Avantage NEO et Original de 3 et 6 boîtes ne sont pas éligibles
- Livraison offerte en **Colissimo Pickup dès 30€ d'achat**

## 10€ pour les nouveaux clients avec la newsletter

Les nouveaux clients peuvent également s'inscrire à la newsletter NESCAFÉ® Dolce Gusto® afin de recevoir **10€ de réduction sur leur première commande dès 30€ d'achat**. Le code communiqué est **BIENVENUE**.

La page de l'opération confirme la compatibilité avec les bons PREMIO, mais ne précise pas explicitement si le code newsletter est cumulable avec la machine offerte. Pense donc à **tester le code BIENVENUE dans le panier** et à vérifier que la machine gratuite reste bien affichée avant de payer.
