## C'est quoi le Medisun+ Gel Matifiant ACM ?

Le **Medisun+ Gel Matifiant** est le **solaire visage** d'ACM pensé pour les peaux qui brillent vite au soleil — peaux mixtes, grasses, à imperfections. À la différence des crèmes solaires classiques (souvent grasses, occlusives), c'est une **texture gel toucher sec** qui matifie immédiatement et durablement.

**Ses bénéfices** :

| Bénéfice | Détail |
|---|---|
| **Protection SPF50+** | Très haute protection **large spectre** : **UVB + UVA + Lumière Visible + Infrarouge** + **PA ++++** (la plus haute note d'absorption UVA) |
| **Matité 8h** | Peau **matifiée 8 heures sans dessécher** (test d'usage 28 jours sur 21 volontaires) |
| **Toucher sec immédiat** | Texture rapidement absorbée, **non grasse, non collante** |
| **Actifs séborégulateurs** | **Zinc**, **Niacinamide**, **microsphères de silice** ultra-absorbantes |
| **Idéal peaux sensibles** | Formule pensée même pour les peaux réactives |
| **Testé dermatologiquement** | Validation labo |
| **Résistant à l'eau** | OK piscine, plage, transpiration |
| **Photostable** | Le filtre ne se dégrade pas au soleil |
| **Non parfumée** | Pas de risque d'allergie au parfum |
| **Non comédogène** | Ne bouche pas les pores, ne déclenche pas d'imperfections |

## Pourquoi c'est intéressant pour les peaux mixtes/grasses

Les **filtres solaires classiques** sont souvent un **cauchemar** pour les peaux qui brillent :
- Textures **grasses et occlusives** → ça bouche les pores et déclenche des boutons
- Effet **fini brillant** → impossible de mettre du maquillage par-dessus
- Sensation **lourdeur** → on n'a pas envie d'en remettre dans la journée
- Souvent **parfumées** → ça pique les peaux sensibles

Le **Medisun+ Gel** résout ces 4 problèmes avec :
- Une **texture gel** qui pénètre vite
- Un **fini mat invisible** qui sert de **base maquillage** parfaite
- Une formule **non comédogène** (testée derma)
- **Pas de parfum** (donc adapté aux peaux réactives ou couperose légère)

Les actifs **zinc + niacinamide** sont **les ingrédients chouchous** des dermatologues pour les peaux à imperfections — ils régulent le sébum tout en apaisant les rougeurs.

## ⚠️ Précautions solaires (toutes peaux)

Même avec un SPF50+, **la protection solaire ne dispense pas** des règles de base :
- **Réapplique toutes les 2 heures** quand tu es dehors, et après chaque baignade
- **Évite les expositions** entre **12h et 16h** (rayonnement maximal)
- **Lunettes UV + chapeau** pour les enfants et les peaux claires
- **Vérifie ta peau** régulièrement (grains de beauté, taches) — si quelque chose change, **consulte un dermatologue**
- **N'utilise pas** un solaire dont la date de péremption est dépassée (l'efficacité chute)

⚠️ Le solaire **ne remplace pas** la consultation dermatologique annuelle si tu as des grains de beauté à surveiller ou un historique familial de cancer cutané.
