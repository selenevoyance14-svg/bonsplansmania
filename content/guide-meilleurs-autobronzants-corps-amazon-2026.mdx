## 💡 Comment choisir son autobronzant ?

| Critère | À regarder |
|---|---|
| **Intensité souhaitée** | Hâle progressif léger (lait) ↔ Bronzage intense (mousse pro) |
| **Type de peau** | Claire, mate, mixte, sensible, atopique |
| **Texture** | Lait (débutant), mousse (intermédiaire), spray (pro), gélule (oral) |
| **Vitesse de résultat** | Progressif sur plusieurs jours OU instantané/express |
| **Tenue** | 3-5 jours (express) ou progressif renouvelable |
| **Made in France ?** | Topicrem, Mixa, Laboratoires de Biarritz |
| **Sans parfum / sans traces ?** | Indispensable si peau sensible ou rookie |

→ **Règle d'or** : **commence toujours par un autobronzant progressif** si c'est ta première fois. **Évite les mousses pro pour débutant·e** — risque de traces.

## 💡 Bonus : la routine autobronzant parfaite

| Étape | Action |
|---|---|
| 1️⃣ **Gomme la veille** | Exfoliation = surface uniforme (pas de traces) |
| 2️⃣ **Hydrate les zones sèches le matin** | Coudes, genoux, chevilles, mains (ces zones "boivent" plus de produit) |
| 3️⃣ **Applique avec un gant dédié** | Évite les paumes orangées + dépôt uniforme |
| 4️⃣ **Mouvements circulaires** | Pas de stries verticales |
| 5️⃣ **Insiste peu sur les zones "boutons"** | Pieds, genoux, coudes : moins de produit |
| 6️⃣ **Laisse poser le temps indiqué** | 1-3h selon le produit |
| 7️⃣ **Rince à l'eau tiède** | Pour les produits express. Sinon, vivre sa vie ! |
| 8️⃣ **Hydrate quotidiennement** | Pour faire **durer le hâle** 5-7 jours |
| 9️⃣ **Renouvelle l'application** tous les 4-5 jours | Pour entretenir |

→ **Erreur n°1 à éviter** : appliquer **trop de produit d'un coup**. **Petites quantités + bien étaler** = résultat naturel garanti.

## ⚠️ Les zones difficiles (à doser ET BIEN)

| Zone | Conseil |
|---|---|
| **Mains** | Appliquer **très peu** (1 noisette pour 2 mains), bien insister entre les doigts |
| **Poignets / chevilles** | Estomper généreusement pour éviter "démarcation chaussette" |
| **Coudes** | Hydrater +++ avant, puis effleurer (sinon zone très foncée) |
| **Genoux** | Idem : hydrater + effleurer |
| **Cou + décolleté** | Fondre dans le visage : utiliser le **résidu** sur le gant |
| **Visage** | Privilégier un autobronzant visage spécifique (formule + douce) |
| **Pieds + talons** | Limite stricte au-dessus de la cheville |
