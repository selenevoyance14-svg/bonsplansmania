## Tefal fête ses 70 ans avec un jeu Memory

Pour ses **70 ans**, Tefal organise un jeu-concours gratuit sans obligation d’achat. Il faut retrouver les **quatre paires de produits Tefal identiques** dans un Memory pour valider sa participation au tirage au sort.

[**Participer au jeu Tefal 70 ans →**](https://votre-jeu.tefal.fr/quiz/1834370_2874/Tefal-fete-ses-70-ans.html)

## Les quatre cadeaux à gagner

Le règlement prévoit **quatre gagnants**, avec un cadeau différent attribué à chacun :

| Lot | Référence | Valeur maximale annoncée |
|---|---|---:|
| Four à pizza électrique d’extérieur **Pizza Pronto** | JM600TE0 | **349,99 €** |
| Batterie de cuisine **Harmony 5 pièces** | L8049502 | **166,99 €** |
| Appareil à raclette **Célébration** | RE1513F0 | **54,99 €** |
| Appareil à fondue **Célébration** | EF2714F0 | **59,99 €** |

Un seul lot peut être attribué par foyer pendant toute la durée du jeu.

## Comment participer ?

1. ouvre la page officielle du jeu entre le **25 août et le 8 septembre 2026** ;
2. complète le formulaire de participation ;
3. accepte le règlement et valide l’envoi ;
4. retrouve les quatre paires identiques dans le Memory ;
5. confirme ta participation par e-mail si Tefal te le demande.

La participation est limitée à **une seule fois par personne**. Le tirage au sort est prévu le **15 septembre 2026 à 11 heures**.

[**Jouer au Memory Tefal →**](https://votre-jeu.tefal.fr/quiz/1834370_2874/Tefal-fete-ses-70-ans.html)

## Qui peut participer ?

Le concours est réservé aux personnes :

- âgées de **18 ans ou plus** ;
- disposant d’un accès à Internet ;
- résidant en **France métropolitaine**, Corse comprise ;
- ne résidant pas à Monaco.

Les gagnants seront contactés par e-mail ou téléphone. Ils devront répondre dans les **sept jours** suivant le contact, faute de quoi le lot pourra être attribué à un suppléant.
