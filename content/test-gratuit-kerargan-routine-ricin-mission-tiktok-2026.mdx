## Le produit testé : la routine Ricin Kerargan

### L'huile de ricin — l'actif phare

L'**huile de ricin** est **LA** référence pour les **cheveux fragilisés**, **cassants** ou **chute saisonnière** :
- **Riche en acide ricinoléique** : nourrit la fibre en profondeur
- **Stimule la pousse** : action sur le bulbe pileux
- **Renforce la kératine** : limite la casse
- **Fortifie** les cheveux fins / clairsemés
- **Brillance** naturelle après quelques semaines d'utilisation

### Une routine complète Kerargan

La routine inclut **plusieurs produits complémentaires** Kerargan à base de **ricin** :
- **Shampoing Ricin** : nettoie en douceur + dépose les actifs
- **Masque / Soin profond Ricin** : restaure la fibre fragilisée
- **Sérum / Huile Ricin** : finition + protection longue durée
- **Application** : routine régulière pendant **plusieurs semaines** pour **résultats visibles**

### Pour qui

- **Cheveux fragilisés** : colorations, décolorations, brushings agressifs
- **Cheveux fins ou clairsemés** : besoin de densité
- **Chute saisonnière** : printemps / automne
- **Post-grossesse** : cheveux affaiblis post-partum
- **Stress / fatigue** : impact visible sur les cheveux
