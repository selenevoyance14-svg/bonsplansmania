## Mode d'emploi rapide

### Routine matin

1. **Nettoyer** la peau avec ton démaquillant ou nettoyant doux
2. **Vaporiser** une lotion (Clinique Lotion 2 ou similaire) optionnelle
3. **Appliquer** une noix de Tellement Différente sur visage + cou
4. **Masser** doucement jusqu'à pénétration complète
5. **Appliquer ton SPF** (ex: La Roche-Posay Anthelios brume) par-dessus
6. **Maquillage** ensuite (le soin est compatible)

### Routine soir

1. **Démaquiller** + nettoyer
2. **Appliquer** Tellement Différente sur peau propre
3. **Compléter** avec un sérum / yeux si besoin
4. **Pas de SPF le soir** (juste le soin hydratant)

### Conseils d'application

- **Quantité** : 1 noix (taille petit pois) suffit pour visage + cou
- **Tapoter** plutôt que frotter (effet liftant léger)
- **Insister** sur les zones sèches (joues, contour bouche)
- **Éviter contour œil** (préférer une crème yeux dédiée)
