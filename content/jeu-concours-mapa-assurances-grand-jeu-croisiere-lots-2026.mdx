## Le grand jeu MAPA 2026 : des lots chaque mois !

**MAPA Assurances** lance son grand jeu annuel avec un **grand prix croisière** d'une valeur de **3 000€** et des **lots mensuels** exceptionnels de mars à décembre 2026. Participation **gratuite et sans obligation d'achat**.

## Le grand prix

| | |
|---|---|
| **Lot** | **Croisière pour 2 personnes** |
| **Valeur** | **3 000€ TTC** |
| **Tirage** | 11 janvier 2027 |

## Les lots mensuels

| Mois | Lot |
|------|-----|
| **Avril** | Jambon entier |
| **Mai** | Casque audio sans fil |
| **Juin** | 4 billets Disneyland Paris (1 jour / 2 parcs) |
| **Juillet** | Jambon entier |
| **Août** | Vol en montgolfière pour 2 personnes |
| **Septembre** | Thermomix |
| **Octobre** | Montre connectée |
| **Novembre** | Jambon entier |
| **Décembre** | iPad |
| **Janvier 2027** | Téléviseur |

## Comment participer

1. Rendez-vous sur la [page du grand jeu MAPA](https://lp.mapa-assurances.fr/grand-jeu/)
2. **Remplissez le formulaire** (identité, adresse, secteur professionnel)
3. Validez votre participation
4. Tirage au sort mensuel + grand tirage le 11 janvier 2027
