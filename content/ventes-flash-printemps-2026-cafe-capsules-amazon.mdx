## Vérifiez d’abord la compatibilité

Deux capsules qui se ressemblent ne fonctionnent pas nécessairement dans la même machine. Repérez le nom exact de votre système, puis confirmez la compatibilité sur la fiche et l’emballage.

## Comparer correctement les lots

- calculez le **prix par capsule** ;
- distinguez espresso, lungo et boissons composées ;
- regardez le nombre réel de boissons, surtout pour les recettes utilisant deux capsules ;
- vérifiez l’intensité et le type de café ;
- consultez les possibilités de collecte ou de recyclage.

Un grand carton n’est avantageux que si le prix unitaire est meilleur et si la saveur vous convient. Les tarifs évoluent : nous n’affichons donc aucun prix permanent.
