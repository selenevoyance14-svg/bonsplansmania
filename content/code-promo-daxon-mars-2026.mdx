## Les avantages Daxon en bref

| Avantage | Conditions |
| --- | --- |
| Jusqu’à **−60 %** | Sur les produits signalés, réduction déjà comprise dans le prix |
| Code **85810** | Livraison standard en point relais offerte dès **75 € facturés** |
| Modes concernés | Colissimo ou Mondial Relay en point relais |
| Autres livraisons | 6,99 € en standard ; supplément de 3 € en rapide |
| Fin de l’opération | **30 novembre 2026 inclus** |

Le code n’ajoute pas 60 % de remise aux prix déjà réduits. La réduction maximale concerne une sélection, et non tout le catalogue. L’opération n’est pas cumulable avec une autre offre en cours.

## Comment utiliser 85810 ?

Choisissez les articles et leurs tailles, ajoutez-les au panier, puis saisissez **85810** dans le champ code avantage. Pour la livraison gratuite, vérifiez le montant **facturé après réductions**, puis sélectionnez le mode standard en point relais éligible. Contrôlez le récapitulatif avant paiement.

## Newsletter : un avantage distinct

Daxon affiche également **15 € offerts dès 29 € facturés** aux nouvelles inscrites à sa newsletter, avec **NEWSAH26**, jusqu’au **28 février 2027**. Cette offre personnelle exclut les prix rouges, prix verts et articles déjà démarqués. Elle n’est pas cumulable avec une autre offre, ni cessible ou utilisable partiellement.

Comparez le total du panier plutôt que d’additionner les avantages. Les produits Black Friday déjà démarqués ne sont pas éligibles à cette remise newsletter.
