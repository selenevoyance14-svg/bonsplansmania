**Le Rustique** lance son jeu **"Trouvez le Code !"** sur la plateforme Qui Veut du Fromage. Achetez un camembert Le Rustique, trouvez le code sur l'emballage et tentez de gagner des lots !

## Comment participer ?

1. **Achetez un camembert Le Rustique** porteur de l'offre (camembert classique ou Spécial Affiné)
2. **Trouvez le code** sur l'étiquette du produit
3. **Rendez-vous** sur quiveutdufromage.com
4. **Entrez votre code** et votre preuve d'achat
5. Découvrez si vous avez gagné !

Le jeu est ouvert du **2 mars au 3 mai 2026**.

## Les lots à gagner

- **Bons de réduction** sur les produits Le Rustique
- **Lots cadeaux** selon les tirages
- Participez à chaque achat pour multiplier vos chances

## Où trouver Le Rustique ?

Le camembert Le Rustique est disponible partout en France :
- Leclerc, Carrefour, Auchan, Intermarché, Super U, Lidl...
- Rayon fromage à la coupe ou libre-service

## Pourquoi Le Rustique ?

- **Camembert emblématique** — reconnaissable à son emballage en filet
- **Fabrication française** — savoir-faire normand
- **Goût authentique** — un camembert de caractère

## Pourquoi participer ?

- **Simple** — un code à entrer en ligne
- **2 mois** — du 2 mars au 3 mai pour jouer
- **Chaque achat compte** — multipliez vos participations
- **Vous achetez déjà du fromage** — autant en profiter !
