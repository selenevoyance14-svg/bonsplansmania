## Comment vérifier un code Daxon

1. Connecte-toi à ton compte Daxon et ouvre la rubrique **« Vos offres du moment »**.
2. Sélectionne les articles éligibles et ajoute-les au panier.
3. Saisis le code indiqué par Daxon dans la zone prévue.
4. Vérifie que la réduction apparaît avant le paiement.
5. Contrôle les exclusions, le minimum d'achat et la date de fin.
